Location photos for the emergency equipment popup.

Name each photo after the equipment code, as a JPG, for example:

  AED-01.jpg  EMK-01.jpg  FAK-01.jpg  FE-01.jpg  FL-01.jpg  O2-01.jpg  PBE-01.jpg  TMS-01.jpg

Drop the file in this folder and it replaces the placeholder automatically.
Use photos of the fictional demo layout only, or your own aircraft with permission.
